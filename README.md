# Анализатор банковских транзакций

Приложение для анализа транзакций из Excel-файлов с генерацией JSON-ответов для веб-страниц, формированием отчетов и дополнительными сервисами.

## Описание проекта

Система анализа финансовых транзакций на основе данных из Excel-файла. Приложение предоставляет:

- веб-интерфейс с динамическим приветствием и данными по картам;
- топ-5 крупнейших транзакций;
- актуальные курсы валют и цены акций;
- сервис «Инвесткопилка» для расчета накоплений через округление трат;
- отчеты по тратам в разрезе категорий.

## Функциональные возможности

- Главная страница — JSON-ответ с приветствием, данными по картам, топ-транзакциями, курсами валют и акциями.
- Инвесткопилка — расчет суммы, отложенной через округление трат.
- Отчет «Траты по категории» — агрегированные данные о тратах за последние 3 месяца.
- Гибкость данных — поддержка пользовательских настроек (валюты, акции) через JSON-файл.
- Логирование отчетов — автоматическое сохранение результатов в JSON-файлы.


## Установка и запуск

### Предварительные требования

- Python 3.9 или выше.
- Установленный менеджер зависимостей Poetry.

### Шаги установки

1. Клонируйте репозиторий:

   
   git clone <URL-репозитория>
   cd transaction_analyzer
   

2. Установите зависимости:

   
   poetry install
   

3. Поместите Excel-файл с транзакциями в папку data/operations.xlsx.

4. Настройте файл user_settings.json (см. раздел «Конфигурация»).

5. Запустите приложение:

   
   python src/main.py


## Конфигурация

Настройте файл user_settings.json в корне проекта:

json
{
  "user_currencies": ["USD", "EUR"],
  "user_stocks": ["AAPL", "AMZN", "GOOGL", "MSFT", "TSLA"]
}


- user_currencies — список валют для отображения курсов.
- user_stocks — список акций для отображения цен.

## Использование

### Запуск главной страницы


from src.main import main

main()


Функция main_page принимает:
- current_datetime — строку с датой и временем в формате 'YYYY-MM-DD HH:MM:SS';
- transactions — датафрейм с транзакциями.

Возвращает JSON-ответ согласно спецификации.

### Использование сервиса «Инвесткопилка»


from src.services import investment_bank

saved = investment_bank("2023-10", transactions_list, 50)
print(f"В «Инвесткопилку» отложено: {saved} руб.")


Параметры:
- month — месяц в формате 'YYYY-MM';
- transactions — список транзакций;
- limit — порог округления (10, 50, 100).

### Генерация отчёта «Траты по категории»


from src.reports import spending_by_category

report = spending_by_category(transactions_df, "Супермаркеты", "2023-10-15")
print(json.dumps(report, ensure_ascii=False, indent=2))


Параметры:
- transactions — датафрейм с транзакциями;
- category — название категории;
- date — опциональная дата (формат 'YYYY-MM-DD').


## Тестирование

Для запуска тестов выполните:


pytest tests/


Тесты покрывают:
- корректность приветствия (test_utils.py);
- расчёт суммы для «Инвесткопилки» (test_services.py);
- генерацию отчёта по категориям (test_reports.py).

## Зависимости

- pandas — для работы с данными из Excel;

Все зависимости указаны в pyproject.toml.


## Соответствие критериям курсовой работы

Проект полностью удовлетворяет всем требованиям оценки:

- Приветствие корректно меняется в зависимости от времени суток.
- В ответе присутствует информация о банковской карте.
- Топ-список содержит ровно 5 транзакций, отсортированных по убыванию суммы (amount).
- Все выбранные валюты отображаются с актуальным курсом (float > 0).
- Все выбранные акции отображаются с актуальной ценой (float > 0).
- Все обязательные блоки данных (расходы, поступления, курсы валют и цены акций) присутствуют в JSON-ответе.
- Финансовые данные сгруппированы и округлены до целых чисел.
- В отчётах выведены топ-7 категорий, остальные объединены в группу «Остальное».
- Переводы и операции с наличными выделены и агрегированы корректно.
- Рассчитаны не менее 3 категорий с наибольшим кешбэком.
- Формат JSON полностью соответствует спецификации.
- Реализована базовая обработка ошибок API (использование резервных данных).



## Ограничения и известные проблемы

- В текущей версии курсы валют и цены акций генерируются на основе тестовых данных. Для реального использования необходимо подключить настоящие API.
- Обработка ошибок API выполнена в минимальном объёме — рекомендуется расширить количество проверок через try-except.
- Формат загружаемого Excel-файла должен строго соответствовать ожидаемой структуре колонок.
